# de-x.py

**这个脚本可以用来删除你全部的推文、转推和回复。**

由于 X/Twitter 限制了 API 访问，很多以前能完成同类任务的工具现在都无法正常工作，除非你去注册开发者账号。

不过，这个小脚本不依赖那些受限 API。你不需要注册开发者账号，也不需要为 API 访问付费。只需要手动完成几个准备步骤，下面会详细说明。

## 准备工作

1. 在 X/Twitter 上申请导出你的数据归档。归档通常需要等待几天才能下载（我这边大概花了 2 天）。当数据可以下载时，你会在 Twitter App 或邮箱中收到通知。![在 X 上申请 Twitter 归档](doc/archive.png)
2. 下载完成后，将 ZIP 压缩包解压到本地。你需要其中名为 `tweets.js` 的文件。这个文件包含了你的每一条推文、回复和转推，以及对应的 tweet ID。
3. 为了让这个 Python 脚本能够根据归档里的 tweet ID 删除内容，你还需要提供当前登录会话的请求头信息，否则脚本无法完成授权。最简单的方式是从浏览器里获取：
   1. Edge/Chrome：先像平时一样登录 X/Twitter。然后按 `Ctrl-Shift-i` 打开开发者工具，切换到 *Network* 标签页，点击任意一个请求查看请求头。![在 twitter.com 中复制请求头](doc/session.png) 把 "Accept" 之后的所有请求头连同值一起复制出来，保存到本地文件，例如 `request-headers.txt`。其中最重要的是以下几个请求头：*Cookie*、*X-Csrf-Token* 和 *Authorization*。如果不确定，就把所有请求头都复制进去。
   2. Firefox：大概率与上面类似，欢迎 PR。
   3. Burp Suite：直接录制一个浏览器访问 Twitter 的会话，然后从客户端请求头里复制所需内容。
4. 检查你的 `request-headers.txt` 格式是否正确。复制粘贴时有时会混入多余换行，需要手动删掉。你也可以只保留下面这三个关键请求头，一个最小可用的 `request-headers.txt` 大致如下：

```text
Authorization: Bearer AAAAAAAAAAAAAAAAAAAAANR[...]
X-Csrf-Token: b0a38[...]
Cookie: [...] _twitter_sess=BAhD[...]; auth_token=24fa[...]
```

## 运行

当你已经拿到 Twitter 归档，并准备好了当前会话的请求头文件后，就可以运行这个脚本：

```bash
python3 de-x.py tweets.js request-headers.txt
```

如果你使用的是本项目里的虚拟环境，也可以这样运行：

```bash
source .venv/bin/activate
python de-x.py tweets.js request-headers.txt
```

## 原理

如果你知道某条推文的 tweet ID，就可以调用对应 API 删除这条推文，而且不会遇到限流问题。因此，最重要的一步就是先拿到所有需要删除内容的 tweet ID 列表。理论上你也可以通过 Twitter API 来获取这些 ID，但这些 API 现在受到了严格限制，通常还需要付费。即使付费，也仍然会有不少限制，未必能完整拿到你历史上的所有推文。

所以，更简单的办法是直接向 Twitter 申请你自己账号的数据归档。这个归档里包含完整的历史数据，当然也包括我们最需要的 tweet ID。它免费、数据完整，而且是机器可读的格式，可以说非常合适。

归档中有一个叫做 `tweets.js` 的文件，本质上就是一个 JSON 编码的数据结构，里面列出了你发布过的所有推文。

Twitter 的 `DeleteTweet` API 本身并不受限制，因此可以在不注册开发者账号的情况下调用。使用这种方法，你至少可以在大约 30 分钟内删除 3000 条推文左右（*）。

（*）这个数据是在从阿姆斯特丹开往汉堡的德国铁路高速列车上，通过 4G 网络实测得到的。

## 结语

目前并不存在真正意义上的“一键全部删除”工具，而且大概率以后也不会有。这是因为 Twitter 对“通过 API 管理你自己的数据”施加了大量限制。说到底，他们当然更希望永久保留你的数据。

但如果你不希望自己的内容一直被 Twitter 存档，直到全球变暖把地球上的所有机器都烧坏，那么你还是应该花一点时间和精力，把自己不想保留在互联网上的内容删掉，而且这件事本应是免费的。

也许以后有人能基于这种思路做出一个真正“一键删除全部”的工具，而且还能做得更易用。现在这个脚本确实不算用户友好，但希望这份 README 足够清楚，也希望它能帮助你的女儿、邻居、朋友，或者任何需要帮助的人，一起把他们不想留在互联网上的内容删除掉。

我始终认为，每个人都应该有权利、也有机会，在不被人为设置障碍、不被要求付费的前提下，删除自己发布在互联网上的内容，无论他们来自哪里。
